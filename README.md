# Sistema de Gestión de Capacitación - Flask & SQLite

Este proyecto es una aplicación web desarrollada con Python y Flask para la gestión e inscripción de cursos e institutos. Permite administrar estudiantes, cursos disponibles e inscripciones almacenando la información en una base de datos relacional SQLite.

## Características
- **Gestión de Cursos:** Alta y visualización de cursos con su respectiva carga horaria.
- **Gestión de Estudiantes:** Registro de datos personales de los alumnos.
- **Gestión de Inscripciones:** Vinculación entre estudiantes y cursos.
- **Persistencia de Datos:** Uso de SQLite para el almacenamiento local.
- **Interfaz Web:** Plantillas HTML con arquitectura modular.
